Understanding the Attack

How it Works:

  1. Step 1: Attacker creates two transactions simultaneously with the same coins
  2. Step 2: Public transaction goes to victim (broadcast to network)
  3. Step 3: Private transaction goes to attacker (kept secret on private chain)
  4. Step 4: Honest nodes mine public transaction into a block
  5. Step 5: Attacker secretly mines private chain faster (needs >51% hash rate)
  6. Step 6: Attacker broadcasts longer private chain, network accepts it
  7. Result: Public transaction is reversed, attacker keeps coins!

Defense: Wait for multiple confirmations (6+ blocks) before accepting payment.
