Project Overview

Abstract / Introduction

Blockchain technology has revolutionized digital transactions by providing a decentralized and immutable ledger system. However, despite its robustness, blockchain networks are vulnerable to various types of attacks, including the double-spending attack.

A double-spending attack occurs when a malicious actor spends the same cryptocurrency more than once before the network confirms the transaction, potentially leading to financial losses.

This project simulates a double-spending attack on a blockchain system using Python. It aims to enhance understanding of blockchain security and potential mitigation strategies by demonstrating how an attacker can exploit vulnerabilities in a blockchain. Through this simulation, students can analyze attack scenarios, measure their success rates, and explore countermeasures that can strengthen blockchain networks.

Functional Requirements (Prototype Phase)

  1. Blockchain Implementation:
    • Develop a basic blockchain system in Python.
    • Implement fundamental features such as blocks, transactions, and proof-of-work (PoW) consensus.
  2. Transaction Processing:
    • Implement a transaction validation system.
    • Ensure transactions are broadcast and verified by network nodes.
  3. Network Simulation:
    • Create a peer-to-peer (P2P) network to simulate blockchain nodes.
    • Implement a communication protocol for transaction propagation.
    • Use the Simblock simulator for simulation.
  4. Double-Spending Attack Simulation:
    • Develop an attacker node capable of executing a double-spending attack.
    • Test attack success rates under different conditions (e.g., network delay, hash rate dominance).
